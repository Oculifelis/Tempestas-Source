# Changelog

## 0.3.0

- Added Thaumaturge aspects to every item and block, loaded only when Thaumaturge is installed
- Fixed released ice melting in the Nether where vanilla ice does not
- Fixed the Storm Charm's own bolt recharging it
- Fixed Weather Condenser output going over one stack

- Added the charge release effect, which charges nearby creepers
- Added weather timing conditions for skies in datapacks
- Added the Weather Eye and Ahead of the Storm advancements
