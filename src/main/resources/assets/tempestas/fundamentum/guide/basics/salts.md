# Changing the Climate

Three blocks change the air around them, out to 3 blocks away:

- **Block of Ember Salt**: hotter and drier
- **Block of Rime Salt**: colder
- **Dewstone**: wetter

Lava, fire, ice and snow change it too. Only the nearest block of each kind counts, so one is enough.
