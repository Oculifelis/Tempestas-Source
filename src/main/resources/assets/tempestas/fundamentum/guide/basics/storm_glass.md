# Storm Glass

A **Storm Glass** forecasts the weather. Place it on a solid block and watch the crystals inside.

- Clear liquid: fair weather ahead.
- A few specks: a change is coming.
- Feathery crystals: rain soon.
- Crystals up to the cork with a violet glint: a storm is close.
- Cloudy crystals sinking: the rain is about to stop.

Use it with an empty hand to read it aloud, or put a comparator against it. Some skies, like the Calm Before,
only show up ahead of a storm, so the glass tells when to have a jar ready.
